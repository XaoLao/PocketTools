# PocketTools

A privacy-first, no-signup toolbox that runs entirely in your browser.

## Why it exists
People constantly need tiny utilities—clean text, format JSON, generate passwords, create UUIDs, convert timestamps, encode Base64, inspect URLs—but opening a separate site for every task is slow and often sends private data to servers.

PocketTools keeps the common stuff in one place and processes everything locally.

## Included tools
- Text cleanup and statistics
- JSON formatter/minifier
- Strong password generator
- UUID generator
- Unix timestamp converter
- Base64 encode/decode
- URL encode/decode
- Case converter

## Run locally
Open `index.html` in any modern browser. No build step, account, API key, or server is required.

## Privacy
All processing happens in the browser. PocketTools does not upload the text you paste into its tools.
